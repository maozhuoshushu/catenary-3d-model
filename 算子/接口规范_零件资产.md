## 0. 为什么需要这份规范

用户的目标是**复刻一个区间或一个车站**。手段是：**零件 → 装配 → 布局**。

> **"可拼接"的前提，不是零件画得多细，而是每个零件都遵守同一份契约。**
> 契约一旦不统一，拼到第 3 个零件就会开始互相打架 —— 本会话已实测过 4 次。

**本规范的每一条，都是从本会话一次真实事故里长出来的**，不是纸上设计。

## 1. 三条硬契约

### ★ 契约 1：单一事实来源（Single Source of Truth）

**一个几何量，只在一个地方算出来；其它所有地方引用它。**

**反面实证（SPEC §3.2 四实例，全部真实发生）**：

| # | 同一事实被写两遍 | 靠什么"碰巧成立" | 一旦前提变 |
|---|---|---|---|
| 1 | `jZ`：`armEndZ+0.46` / `insL2−dzInc` | 仅 `insL2=2.149508` 时相等 | **分叉，分叉量正是折角** |
| 2 | `spA` 的 `0.2003` | 等腰前提 | 前提被 v4.4 取代 ⇒ **数值作废** |
| 3 | `yL`：底座高度 / 臂下端高度 | 旧值下二者都 5.320 | **静默偏 127.9 mm，不报错** |
| 4 | 臂轴线：`CANTG.armBot` 手抄 / 实建几何 | 落码前恰好相等 | **校核器测的是错的臂** |

**实测**：字面量 `[0,yL,insL2]` 全文出现 **3 次**，**且没有任何单一来源变量** ——
**这正是"允许抄"的根源：没有单一来源，所以每一处都只能自己写一遍。**

**⇒ 规则**：
```js
// ✅ 正确：算一次，命名，处处引用
var armBotPt = [0, armLowY, insL2];   // 斜腕臂下端：唯一来源
rodInsulator([0,yL,pinL], armBotPt, …);
tube(armBotPt, pFlat, …);
CANTG = { …, armBot: armBotPt };

// ❌ 禁止：同一个量在 3 处各写一遍字面量
rodInsulator([0,yL,pinL],[0,yL,insL2], …);   // 写一遍
tube([0,yL,insL2], …);                        // 又写一遍
CANTG = { armBot:[0,yL,insL2] };              // 再写一遍
```

**★ 若确须"手抄"（如给外部工具用的快照），必须在两侧各写一条断言把二者钉在一起。**

---

### ★ 契约 2：不得依赖隐式前提

**语义必须写在代码里，不能靠"当前数据恰好满足"。**

**反面实证 —— `withM` 的替换语义**：
```js
// 旧实现：替换，丢弃外层帧
function withM(m,fn){ var o=MAT; MAT=m; fn(); MAT=o; }
```
⇒ 产生了**三套互不相同的绕过手法**（`tube` 无绕过 / `sphereAt` 先升世界 / `polyTube` 打补丁），
**三种运气**。族缺陷 **D19 / D21 / D22 / D23 / D25 / D26** 同源。

**⇒ 规则**：
- 用**真矩阵栈**（`MAT = MAT ? mul(MAT,m) : m`）⇒ 帧内调用语义**自动正确**，无需规避；
- **禁止**"靠当前值相等"的写法（`yL` 兼任两职就是此例）；
- **禁止**"靠调用点恰好在帧外"的隐式契约（旧 `polyTube` 就是此例）。

**配套判据**（SPEC §3.2）：
> 凡一个标识符同时被用作两个不同语义的量，**必须拆成两个名**或**显式注释其兼任关系**。

---

### ★ 契约 3：无模块级可变状态

**零件函数必须是"参数进 → 几何出"的纯函数。**

**反面实证**：旧实现 `BUF / MAT / CUR_ID / CUR_EXP` 都是**模块级单例** ⇒
同时只能建一个场景；`C` 遮蔽全局调色板（D26）会污染整块几何。

**⇒ 规则**：所有可变状态封装在 `createGeom()` 实例内；零件函数**只通过参数与实例**访问状态。

## 2. 零件函数签名

```js
/**
 * 一个零件 = 一个可拼接的积木
 * @param g    几何实例（createGeom() 的返回值，承载 BUF / MAT）
 * @param P    全局参数表（几何不变量：柱高、埋深、线径…）
 * @param cfg  本零件的局部配置（位置 / 朝向 / 变体）
 * @returns    { id, faces, anchors }   ← anchors 必须导出，供装配层与校核器【读取】而非【手抄】
 */
function part_棒式绝缘子(g, P, cfg) { … }
```

**硬要求**：
1. **不得读写任何模块级变量**（除只读常量表）；
2. **必须在调用时 `g.withM(...)` 内也正确**（契约 2）—— 即零件可被任意父变换嵌套；
3. **必须返回 `anchors`**，且这些锚点值**来自实际用于建几何的变量**，不得重算、不得抄。

## 3. 零件资产卡（每个零件必须登记一张）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | PARTLIST 内的稳定编号（不因增删而变） |
| `name` | ✅ | 中文名 + 标准代号（如 `杵座鞍子 D型`） |
| `std` | ✅ | 依据的标准/图号/页码；**无依据的必须标 `[待证]`** |
| `params` | ✅ | 全部尺寸参数名 + 值 + 单位 |
| `anchors` | ✅ | 对外暴露的锚点名 + 语义 |
| `faces` | ✅ | 实测三角面数（三柱型各一） |
| `bbox` | ✅ | 实测包围盒（三柱型各一） |
| `verify` | ✅ | 本零件自带的断言清单 + 复现命令 |
| `open` | ✅ | 遗留/未实现项（如 `R6 双耳鞍子未实现`） |

**★ `std` 字段是纪律抓手**：本会话所有形状回归都发生在"凭印象画"的地方。
凡无图纸/标准支撑的，**必须显式标 `[待证]` 或 `[推断]`**，不得静默当成事实。

## 4. 单位、坐标系、命名

| 项 | 规定 |
|---|---|
| **长度单位** | **米（m）**，一律；毫米只出现在标准原文引用里 |
| **角度** | 显式标注 `deg` / `rad`；**禁止裸数字**（本会话"与水平夹角"曾出现两件两口径） |
| **坐标系** | Y 上、Z 垂直轨道（柱侧为正）、柱轴线 `z=3.17`、轨顶 `y=0`、`GY=−0.45` |
| **命名** | **量名必须带语义**：`armLowY` ✅ / `yL` ❌（正是实例 3 的病根） |
| | 锚点变量以 `Pt` / `Pos` 结尾：`armBotPt`、`seatCenter` |
| | 禁止单字母（`C` 遮蔽调色板 = D26） |

## 5. 面数预算（防止性能悬崖）

| 层级 | 预算 | 现状 |
|---|---|---|
| 单件零件 | **≤ 6,000 面** | t12 实测单件 ≤ 4,272 ✅ |
| 单类零件（新增量） | **≤ 12,000 面** | t12 新增合计 10,976 ✅ |
| 全模型（不含导线） | **≤ 75,000 面** | ✅ |
| 单柱合计 | 实测 **81,144 面** | 承力索 56,576 面已是最大项 |

**★ 历史事故 D20**：承力索单件一度占全模型 **97.2%** ⇒ 立"**单件占比**"为观测项。
t12 后承力索占 **57.4%**，未重蹈。

**⇒ 规则**：新增零件**必须报"占全模型比例"**，不得只报绝对值。

## 6. 每个零件资产必须自带的验证

| # | 类型 | 要求 |
|---|---|---|
| 1 | **闭式几何断言** | 关键尺寸/位置 vs **手算闭式值**，不接受"跑一遍记下来" |
| 2 | **互穿校核** | 与相邻构件的全程最小垂距 ≥ 半径和；**或**干涉跨度贴端部且 ≤ 夹持件实测范围 |
| 3 | **静默偏移警戒** | 凡改动锚点类变量，`grep` **全部**引用点逐一确认（改一部分是典型形态且不报错） |
| 4 | **负控** | 判据必须**能红**：用旧/错实现跑同一条断言，**必须失败** |
| 5 | **回归** | 改动前后，既有零件的**面数 + 包围盒逐位不变** |
| 6 | **状态声明** | 报告里的行号/sha/字节数**必须现读现报**，不得凭记忆 |

## 7. 反面清单（禁止写法）

| ❌ 禁止 | 为什么（实证） |
|---|---|
| 同一个量在多处写字面量 | 实例 1–4，全部因此静默分叉 |
| 标识符兼任两个语义（`yL`） | 实例 3，静默偏 127.9 mm 且不报错 |
| 靠"当前值恰好相等" | 实例 1，前提一变即分叉 |
| 靠"调用点恰好在帧外" | `polyTube` D25，换语义即双重变换 |
| 用单字母名（`C`）遮蔽外层 | D26，切柱型即 `TypeError`，**静态检查看不出** |
| 把锚点**手抄**给外部工具 | 实例 4，**污染校核器本身** |
| 报告里写"已修复"而不给复现命令 | 不可复核 ⇒ 等于没做 |
| 引用图纸而不声明**比例可用性** | 第五种假断言「**证据假**」 |
| 凭记忆写数值/行号/sha | 本会话队长自己犯过（误记 `jY`） |
| 用不可用通道（`read_image`）得出的形状结论 | 见 §8 |

## 8. ★ 视觉通道（本队实测边界，重要）

| 通道 | 实测结果（**2026-09-17 盲测标定**，详见 `视觉通道_盲测与标定.md`） |
|---|---|
| **队长（本会话）`read_image`** | **合成图 11/11 ✅；真实标准文档 21/23 ⚠** ⇒ **可用，但【不可靠】**：真实文档**有实质错误率**（读错 1 个字母、读错 1 个词），且**错法不是报错，而是"自信的、看起来合理的错误答案"** |
| 零件工程师O 所在会话实例 | ❌ **不可用** —— 收到占位符而非图像内容 |
| 复核工程师O 所在会话实例 | ❌ **不可用** —— **随机盲测：形状 4/4 错、颜色 4/4 错、文字 8/8 错** |
| **主证据通道**（脚本） | **PDF 矢量层 + RapidOCR（带坐标与置信度）+ Hough/RANSAC + 闭式几何校核 + 读码** |

**★ 主次关系**：**脚本通道 = 主证据；目视 = 次要证据；两者冲突时【以脚本为准】，并把该条目视读数记为可疑。**

**★ 目录级实测（为什么"合成图能读"不等于"图纸能读"）**：
真实标准页与合成图形差别很大（细线、小字、密集标注、扫描噪声）。队长实证：
- 合成高对比图：**11/11**；
- `s05_p122.png`（标题页）：**13/14** —— 把 `electrification` 读成 `electrificaiton`（**读出一个并不存在的拼写错误**）；
- `s01_p060.png`（正文页）：**8/9** —— 把荷载条目 i) 的 `承力索` 读成 `接触线`；
- **且 OCR 自身也错了 2 处**（`v` 读成 `u`、多出 `Z`/`工`）⇒ **两个通道都不权威 ⇒ 交叉验证是唯一出路。**

**⇒ 规则（三条，均为实证得来）**：
- **A｜盲测准入**：凡声称"某通道可用"（视觉 / OCR / 读图 / 任何感知类），**必须随机盲测**；
  **不接受"测了一张已知内容的图，读对了"** —— 那是**先验**，不是**能力**（队长本人犯过）。
- **B｜感知假**：感知类错误**会伪装成正常答案** ⇒ 一切形状/内容类结论**必须有独立脚本通道交叉验证**，否则标 `[待证]`。
- **C｜脚本自身也要负控**（复核工程师O 提）：**假绿与假红是同一个病 —— 判据在该分辨率/该通道下【分辨力不足】。**
  **凡"脚本说 X 错"的结论，必须先做【脚本自身的负控】**（喂已知答案，看它能否读对）。
  **既不能采信别人的自报，也不能采信自己脚本的自报。**
- **引用图纸/截图作证据，必须声明其比例可用性**
  （实证：某装配图实测主斜线 **36–38°**，与模型 22.29° 不符 ⇒ **该图是示意图、比例不可用 ⇒ 只能定拓扑、不能定角度**）。
